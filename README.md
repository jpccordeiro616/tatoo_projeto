# Tinta Viva Estúdio

Site de um estúdio de tatuagem e piercing (empresa fictícia).

**Dupla:** _João Pedro Cordeiro_ e _Kauan Vargas_

**Tecnologias:** HTML, CSS, JavaScript, Node.js (Express) e MySQL.

## Como rodar

1. Crie o banco: `mysql -u root -p < database/script.sql`
2. Em `backend/`, copie `.env.example` para `.env` e coloque a senha do seu MySQL
3. `npm install` e depois `npm start`
4. Abra http://localhost:3000/api/status. Se aparecer `"banco": "ok"`, está tudo certo.
